# Прототип кабинета клиента НФ

Кликабельный прототип кабинета клиента Нескучных финансов (client.platforma.expert) из проекта «Рисуем макеты НФ».
Один статический файл `index.html`, без бэкенда: все данные — демо, лежат в объекте `DATA_DEFAULT` внутри страницы.

Сайт: https://zgarok.github.io/nf-client-cabinet/

## Публикация

GitHub Pages раздаёт корень ветки по умолчанию (Settings → Pages → Deploy from a branch → `/ (root)`).
Чтобы обновить прототип, замените `index.html` и запушьте.
